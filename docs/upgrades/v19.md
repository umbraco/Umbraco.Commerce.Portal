# Upgrade to Umbraco 19

From Umbraco CMS `[18.0.0, 18.999.999)` / Umbraco Commerce `[18.0.0, 18.999.999)` to CMS `19.0.0-beta1` (tag `release-19.0.0-beta1`) / Commerce `19.0.0-beta.1`.
Branch `topic/19.x/cms-19-upgrade` → PR into `release/19.0.0`, cut from `main` (`2646713`).

**Targets CMS release:** `release-19.0.0-beta1`. The package's own version is `19.0.0-beta.1`.

The full CMS breaking-change inventory for 19.0.0-beta1 was done for Commerce Core (Core repo, `docs/upgrades/v19.md`), and Checkout (the closest sibling: installer, backoffice dashboard, Razor storefront) applied it to an add-on. This file lists what hits Portal, checked against those lists, the 27 `category/breaking` CMS PRs in 19.0.0-beta1, a v18 and a v19 build (CS0618), and `@typescript-eslint/no-deprecated` on the v18 and v19 typings.

## Third-party dependencies

No shipped third-party dependencies. The NuGet package references only Umbraco packages; the client's npm packages are build-time only (Vite bundles nothing but Portal's own code, `@umbraco*` is external). `Microsoft.ICU.ICU4C.Runtime` is declared in `Directory.Packages.props` but not referenced. Global analyzers/tools (StyleCop, Umbraco.Code, NBGV, SourceLink) are dev-only: left alone.

None.

## Tasks

Each task ends in a green build.

- [ ] 1. Bump to .NET 11, the pinned SDK, Umbraco 19.0.0-beta1 and Umbraco Commerce 19.0.0-beta.1; fix what no longer compiles; move off any API 19 newly marks obsolete (second CS0618 build).
- [ ] 2. Installer: client on `@umbraco-cms/backoffice` 19.0.0-beta1; call the install endpoint with `umbHttpClient` (cookie, `POST`) instead of the Bearer token; endpoint becomes `POST`.
- [ ] 3. Tests: new xUnit test project (setup copied from Cart/Checkout) for Portal's pure logic; run tests in the pipeline.
- [ ] 4. Compatibility markers: version `19.0.0-beta.1` (`version.json`, client `package.json`, `umbraco-package.json`); package validation off with baseline `19.0.0` commented; README requirements.

## Decisions

- 30-10-2026: Keep the upgrade to what v19 forces (maintainer). Moving Portal onto Commerce Core's Customer entities / customer addresses is a separate stacked PR.

## Breaking changes for consumers

- Requires Umbraco 19 / Umbraco Commerce 19 (.NET 11).
- The install endpoint (`/umbraco/management/api/v1/umbraco-commerce-portal/install?siteRootNodeId=...`) is now `POST` instead of `GET`. Update external scripts that call it.
